
حزمة تشغيل تلقائي لموقع "أنماط المراقبة الأمنية" (macOS) - تشغيل محلي بدون XAMPP
=================================================================================

محتوى الحزمة:
- flask_app.py          -> التطبيق (خادم Flask) يستمع على المنفذ 5000 وعلى الشبكة المحلية
- requirements.txt      -> حزم Python المطلوبة (Flask)
- start_server.command  -> سكربت تشغيل تلقائي (double-click) يقوم بإنشاء venv وتثبيت الحزم ثم تشغيل الخادم
- templates/            -> صفحات HTML للموقع
- static/               -> ملفات CSS وimages
- data/                 -> products.json و services.json (يمكن تعديلها من لوحة التحكم)
- README-mac.txt        -> هذا الملف (تعليمات سريعة)

متطلبات قبل التشغيل:
- جهاز macOS مع Python 3 مثبت (اكتب في الطرفية: python3 --version)
  (إذا لم يكن مثبتًا، ثبّت Python 3 من https://www.python.org/downloads/ )
- اتصال بالشبكة المحلية إذا تريد أن يتصفح العملاء الموقع من هواتفهم.

كيفية التشغيل (الأسهل):
1) افتح Finder واذهب للمجلد الذي فكّت عنه الحزمة.
2) اضغط مزدوجًا على ملف start_server.command
   - في أول تشغيل، سيقوم بإنشاء بيئة افتراضية وتثبيت Flask (قد يطلب كلمة مرور حساب الماك).
   - ستظهر رسائل في نافذة الطرفية.
3) بعد تشغيل الخادم سترى رسالة مشابهة: *Running on http://0.0.0.0:5000*
4) افتح المتصفح على نفس الجهاز وزُر: http://localhost:5000
5) لعرض الموقع من جهاز آخر داخل نفس الشبكة:
   - اعرف عنوان IP الداخلي للماك (في Terminal اكتب: ipconfig getifaddr en0  أو استخدم System Preferences)
   - على جهاز العميل افتح: http://<IP_الماك>:5000  مثال: http://192.168.1.10:5000
6) لوحة التحكم لتعديل المنتجات والخدمات:
   http://localhost:5000/admin
   كلمة المرور الافتراضية: 1234
7) بعد التعديلات اضغط "حفظ" ليتم تحديث ملفات data/products.json و data/services.json

تغيير كلمة المرور:
- افتح ملف flask_app.py وعدّل قيمة PASSWORD = '1234' ثم أعد تشغيل الخادم.

أمان وملاحظات:
- هذه الحزمة معدّة للاستخدام داخل الشبكة المحلية فقط.
- لا تفتح المنفذ 5000 على الإنترنت دون حماية إضافية.


ملاحظة: يمكنك الآن إضافة رقم التواصل من لوحة التحكم (قسم 'التواصل') وسيظهر في صفحة 'تواصل معنا'.
